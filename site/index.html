Laboratorio visual de sistemas

Diseña sistemas que puedes probar.

Conecta bloques para describir cómo debe funcionar un sistema. Simula casos, inspecciona el recorrido y comparte tu proyecto en un archivo HTML.

Abrir el editor ↗ Cómo funciona ↓

Del lienzo a la especificación.

Reúne en un proyecto lo que sabes del sistema y los casos que necesitas validar antes de implementarlo.

◇

Dibuja el flujo

Conecta entradas, condiciones y resultados. Abre subflujos para detallar un proceso y define bloques propios del proyecto.

▷

Simula los casos

Declara qué datos esperas, ejecuta escenarios y revisa qué camino tomó el flujo y qué resultado produjo.

↧

Comparte el proyecto

Exporta el HTML con los flujos, contratos y casos del modelo. Quien lo reciba puede abrirlo, editarlo y ejecutar el simulador.

Tu proyecto viaja en un HTML.

El archivo exportado incluye el editor y el simulador. Ábrelo directamente en el navegador o usa el visor local para que un agente y tú puedan trabajar sobre el mismo archivo.
